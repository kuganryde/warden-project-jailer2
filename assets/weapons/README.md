# Weapon models (optional)

Drop gun GLB files here and describe them in `manifest.json` (copy `manifest.example.json`).

- Weapon ids: `shg` Raven-12, `ar` Vulture, `smg` Kraken, `rev` Ironfang, `sup` Phantom, `hmg` Hammer.
- Models should face -Z (barrel pointing away from the camera) and be roughly 0.5 to 1.1 units long.
- `scale`, `pos`, `rot` adjust the model; `muzzle` is where flashes and tracers start, `eject` is where shells leave.
- Any gun without an entry keeps the built-in model. The player's arms stay in place.
- Good CC0 sources: Quaternius (Ultimate Guns Pack), Kenney (Blaster Kit), Poly Pizza. Check each licence.
